        -> The Outlier identification:- 
              Can be done using both visualizations and statistical method. 

            By visualizations:-
                Box Plot identification:- It is a graph that depicts the distribution of the summary statistics. 
                    1) Minimum: Represents the smallest data point excluding outliers.
                    2) Q1 (First Quartile): Represents the 25 percentile of median of the lower half of the data. 
                    3) Q2 (Second Quartile): Represents the 50 percentile of median of the middle of the data.
                    4) Q3 (Third Quartile): Represents the 75 percentile of median of the upper half of the data.
                    5) Maximum:- Largest data point excluding the outliers. 

        Example: data = [20, 21, 22, 22, 23, 24, 24, 25, 30, 35, 40, 50] 

            First Sort the order of the data. Here above the data is sorted. 
            Min = is 20 
            Q1 = lowe half median = [20,21,22,22,23,24] -> Median = [mid+mid+1]/2
                                                                    [22+22]/2 = 22
            Q2 =                  = [24+25]/2=24.5
            Q3 =                 = [30+35]/2 = 32.5 
            Max = 50

    -> Methods to handle the skewness:-
            -> Log Transformation :- Converts a skewed distribution into a more normal 
                                    distribution by applying the logarithm function.

                                    Suitable for right-skewed data.

                                    Formula: 𝑥′=log(𝑥+1)x′
                                    
                                    COde - df['log_feature'] = np.log(df['feature'] + 1)

            -> Sqaure Root Transformation:- Reduces the skewness of right-skewed data by 
                                            applying the square root of each value.

                                            Suitable when the data is moderately skewed.

                                            Formula: 𝑥′=𝑥 root(x)

                                    COde df['sqrt_feature'] = np.sqrt(df['feature'])

            -> Box Transformation:- A more generalized transformation that can 
                                    handle both positive and negative skewness.

                                    It tries to find the best transformation parameter 
                                    (lambda) to make the data as close to normal as possible.
